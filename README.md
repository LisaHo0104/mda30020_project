# MDA30020 Project

## Love Shield Campaign Website Plan

The website should avoid feeling like a hospital page. It should feel more like
a relationship, self-care, and youth awareness campaign, with VNVC giving it
medical trust in the background.

The website should be fully responsive and work smoothly on both phones and
laptops. Since the target audience is Gen Z and the campaign is social-media
led, the design should be mobile-first, while still feeling polished and easy to
navigate on larger laptop screens.

The visual and writing style should feel Gen Z-friendly, cute, warm,
relatable, and accessible, while still clearly communicating that this is a
credible health campaign.

## Tech Stack

The website should be built with Next.js, React, TypeScript, and Tailwind CSS,
then deployed on Vercel. The design should be responsive, mobile-first, and
work smoothly on both phones and laptops.

Use reusable UI components for cards, buttons, forms, FAQ sections, and campaign
activity sections. The first version can be mostly static, with the option to
add backend functionality later for anonymous Q&A submissions or analytics.

## Run Locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Deploy Later

This project is ready to deploy on Vercel as a Next.js app. Connect the GitHub
repository to Vercel, keep the project root as the app root, and use the default
Vercel build settings.

## Homepage Hero

- Campaign name: **Love Shield**
- Main message: **"Being informed about HPV is a green flag."**
- Short CTA buttons:
  - Learn about HPV
  - Ask anonymously
  - Find VNVC support

## What Is HPV?

- Simple explanation of HPV
- Why it matters for all genders
- HPV-related cancers and prevention
- Keep this section visual and not too medical-heavy

## HPV Myth-Busting

Use short cards or swipe-style sections to address common misconceptions:

- "HPV only affects women"
- "Men don't need to care"
- "Vaccination is only relevant before marriage"

## Green Flag Behaviour

Frame prevention as care, maturity, and shared responsibility.

Examples:

- Talking about prevention
- Learning before judging
- Supporting your partner
- Considering vaccination

## Audience Pathways

Create separate quick sections for the campaign's key audience groups:

- Young women
- Young men
- Couples and dating audiences
- University students

Each section should use a tailored message from the campaign document.

## Anonymous Q&A

- Provide a safe space to submit HPV questions
- Include pre-written FAQ answers
- Keep the tone non-judgemental and supportive

This fits the campaign's focus on making HPV easier and safer to discuss.

## Campaign Activities

Include the main campaign activations:

- TikTok challenge / Together Movement
- Shield Stories
- V-Shield Booth
- Shield Badge dating-app concept

Link activities to the campaign hashtags:

- `#LoveShield`
- `#HPVGreenFlag`
- `#TogetherAgainstHPV`

## VNVC Information / Take Action

- Explain VNVC as the health partner
- Link to credible vaccine information
- Include a "Find nearest VNVC centre" or location finder idea
- Mention consultation, not just vaccination, so the next step feels lower
  pressure

## Downloadable / Shareable Resources

- Instagram story templates
- HPV fact sheet
- Green flag checklist
- Campus booth QR materials

## Privacy + Credibility Note

Add a short note saying the campaign is educational, non-judgemental, and
supported by credible health information.

This matters because HPV is a sensitive topic.
